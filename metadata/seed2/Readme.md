# Seed2 Metadata

This directory contains metadata describing the patient-level cohort used in the LIDC-IDRI segmentation experiments.

Files in this directory document:

- Patient-level train/validation/test assignments
- Scan identifiers
- Nodule cluster counts
- Slice-level cohort statistics
- Seed-specific partition information used for sensitivity analysis

No DICOM images or patient-identifiable information are stored in this directory.
