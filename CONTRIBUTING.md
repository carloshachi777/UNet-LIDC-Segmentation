# Contributing Guidelines

Thank you for your interest in contributing to UNet-LIDC-Segmentation!

## How to Contribute
1. Fork this repository
2. Create a new branch:

git checkout -b feature-name

3. Make your changes
4. Submit a pull request

## Coding Standards
- Follow PEP8 for Python.
- Document all functions.
- Add comments explaining non-trivial logic.
- Ensure new code does not break existing notebooks.

## Adding New Models
Please place new model architectures in:

src/models/


## Reporting Issues
Use GitHub Issues with:
- clear problem description
- screenshots or logs
- steps to reproduce
