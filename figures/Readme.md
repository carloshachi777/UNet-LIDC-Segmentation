# Figures

This directory contains figures generated by the evaluation and analysis notebooks for the LIDC-IDRI 2D U-Net segmentation study.

## Reference Run

Figures reported in the manuscript are based on the **reference run (seed 42)** unless otherwise stated.

The additional runs using seeds **1 and 2** are used for the seed-sensitivity analysis and are reported separately.

## Directory Structure

```text
figures/
├── seed42/        # Reference run and manuscript figures
├── seed1/         # Seed-sensitivity run
└── seed2/         # Seed-sensitivity run
```

## Figure Generation

Figures are generated programmatically from the notebooks in:

```text
notebooks/
├── 03_UNet_Evaluation.ipynb
└── 03B_Seed_Sensitivity_Evaluation.ipynb
```

The reference-run evaluation notebook produces the primary segmentation and diagnostic figures used in the manuscript.

The seed-sensitivity evaluation notebook generates outputs used to assess variability across independent patient-level data partitions and model training runs.

## Reproducibility

Figures should not be manually modified after generation. They are derived from the corresponding evaluation outputs stored under:

```text
results/
├── seed42/
├── seed1/
└── seed2/
```

This organization preserves the relationship between each trained model, its evaluation results, and the figures generated from those results.

> **Note:** Seed 42 is the prespecified reference run. Seeds 1 and 2 are independent sensitivity runs and are not cross-validation folds.
